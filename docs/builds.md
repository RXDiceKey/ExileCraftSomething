# 빌드 프로필 45개: 스타터 30 + 고급·우버 15 (초안, 검수용)

파우스투스가 "누가 이 아이템을 쓰는가"를 판단할 때 쓰는 구매자 목록입니다. 숫자 가중치(0–1)는 그 옵션이 그 빌드에 얼마나 중요한지입니다.

## 만든 방법

- **인기도**: poe.ninja Allflame 빌드 페이지 상위 4개(겨울 보주 7%, 정의의 화염 5%, 수호자 기동 5%, 망령 소환 4%) + 유튜브 3.27–3.29 빌드 영상 조회수를 빌드별로 합산. 45개 합쳐서 100%가 되도록 나눔.
- **원하는 옵션**: 영상 설명란의 PoB(pobb.in)를 해독해 슬롯별 희귀 아이템 옵션을 집계 (스타터 64개, 고급·우버 15개). 자주 나온 옵션일수록 가중치가 높음 (나온 옵션은 최소 0.4).
- **유니크를 끼는 슬롯은 비움**: 그 빌드의 PoB 중 과반이 그 부위에 유니크를 끼면 희귀템을 안 사는 부위로 봄 (예: 회오리바람 슬레이어는 장갑·반지만 삼).
- PoB가 없는 빌드: 비슷한 빌드 데이터 또는 템플릿(소환수: 망령 소환·무기 기동·면죄, 오라: 수호자 기동).
- 합친 것: 얼음 폭발 + 바알 얼음 폭발, 정수 흡수 + 전염(EDC).
- **고급·우버 15개**: 유튜브 "mirror tier / uber boss / billion dps / endgame showcase / juiced mapping" 검색(3.27–3.29) 영상 중 엔드게임 근거가 있는 빌드. 우버는 1–2등급 옵션만, 고급은 3등급까지만 쳐 주고, 슬롯 예산이 우버 10배·고급 3배.
- **가격 규칙**: 한 빌드가 원하는 좋은 옵션이 한 아이템에 모일수록 값이 급등 (좋은 옵션 하나 더 = 약 4배).

**검수해 주실 것**: 빌드 목록이 맞는지, 슬롯별로 빠졌거나 잘못 들어간 옵션, 베이스 종류(방어 종류·무기 종류). 수정할 부분을 말씀해 주시면 반영합니다.
